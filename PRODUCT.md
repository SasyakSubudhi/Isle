# Isle

Isle is a local-first Windows 11 x64 utility that lives as a small capsule in
unused taskbar space and expands upward into a compact panel. Its users move
files and copied content between apps, check usage, look up words, control music
and run focus sessions without opening a full-size app.

The primary workflow is download/copy/capture → shelf → native drag or paste into
another app. The shell must remain quiet, avoid stealing focus and allow clicks
through its transparent canvas. Visual authority is the user's original brief:
near-black capsule, soft highlight/shadow, continuous spring morph and fluid glow.
The user subsequently chose a Cosmic refinement: deep violet, luminous particles,
an orbital emblem and a stronger violet glow. This is the current visual authority;
the original blue mark remains historical M0 evidence only.

The first release includes Shelf/history/cleanup/stacks, notes, snipping capture,
screen time and nudges, dictionary, GSMTC media, Chrome profile shortcuts,
Pomodoro and explicit presentation mode. Codex usage and in-Isle grammar are
deferred. No telemetry, cloud sync, credential handling or message sending.

Clipboard capture requires opt-in. Original files are never deleted by shelf
actions. Private previews are suppressed in presentation mode. Keyboard access,
reduced motion, DPI correctness and reliable native transfers are acceptance
requirements, not optional polish. See PLAN.md and docs/ORIGINAL_BRIEF.md.
